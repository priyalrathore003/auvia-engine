API Reference

Send audio in, get enhanced audio, structured acoustic intelligence, or AI-generated backing tracks out. Every endpoint accepts a raw audio file upload — no SDK required.

BASE https://auviaengine.com
Open beta: all endpoints below are currently unauthenticated — no API key is required yet. Key-based access and rate limits are rolling out soon; join the list at the bottom of this page to get one early.
POST /enhance-audio

DSP-only enhancement — noise reduction, spectral EQ, peak normalization. No LLM in the loop, so it always works regardless of API credit state. Pair with /intelligence on the same file if you also want a quality score.

Request
# multipart/form-data
curl -X POST https://auviaengine.com/enhance-audio \
  -F file=@vocal.wav
FieldTypeNotes
filefile.wav or .mp3
Response 200
{
  "status": "success",
  "result": "Audio enhanced: noise reduction + spectral EQ applied.",
  "dsp_performed": true,
  "audio_b64": "UklGRi...<base64 wav>",
  "filename": "auvia_enhanced_a3f9c210.wav"
}
POST /process-audio

The full agentic path: a LangGraph pipeline reasons about your instruction, queries a RAG knowledge base, decides whether DSP is needed, and returns both the processed audio and its reasoning.

Request
# multipart/form-data
curl -X POST https://auviaengine.com/process-audio \
  -F file=@vocal.wav \
  -F query="Remove background noise and warm up the vocals"
FieldTypeNotes
filefile.wav or .mp3
querystringFree-text instruction
Response 200
{
  "status": "success",
  "session_id": "a3d2952e-...",
  "result": "Here's what I did to your recording...",
  "dsp_performed": true,
  "reasoning": "Audio file present — defaulting to DSP.",
  "audio_b64": "UklGRi...<base64 wav>",
  "filename": "auvia_enhanced_a3d2952e.wav"
}
POST /orchestrate

Sing & Orchestrate: send a vocal recording, get back an AI-composed instrumental backing track mixed underneath your (DSP-enhanced) vocal — plus the instrumental alone, for remixing.

Request
# multipart/form-data
curl -X POST https://auviaengine.com/orchestrate \
  -F file=@vocal.wav \
  -F mood="warm acoustic ballad"
FieldTypeNotes
filefile.wav, .mp3, .webm, or .ogg
moodstringOptional genre/mood hint
Response 200
{
  "status": "success",
  "music_prompt": "Warm acoustic ballad, A minor...",
  "tempo_bpm": 92.4,
  "key": "A minor",
  "transcript": "...",
  "language_code": "en-IN",
  "agent_response": "I've built a warm arrangement...",
  "audio_b64": "...<mixed track>",
  "instrumental_b64": "...<backing only>",
  "filename": "auvia_orchestrated_df879f84.wav"
}
POST /intelligence

The differentiator: structured acoustic analysis as JSON, no audio processing, no LLM. Pitch, note, key, tempo, and a 0–100 quality score with concrete recommended-processing tags — built for pipelines, not players.

Request
# multipart/form-data
curl -X POST https://auviaengine.com/intelligence \
  -F file=@vocal.wav
FieldTypeNotes
filefile.wav or .mp3
Response 200
{
  "status": "success",
  "pitch_hz": 261.63,
  "note": "C4",
  "key": "C major",
  "tempo_bpm": 120.0,
  "quality_score": 87,
  "noise_floor_db": -45.2,
  "dynamic_range_db": 24.1,
  "recommended_processing": [
    "noise_reduction",
    "eq_warmth"
  ]
}
WS /ws/voice-agent

Real-time conversational voice agent. Stream 16kHz mono PCM16 mic frames continuously; a local VAD-driven turn-taking state machine detects when you stop talking, transcribes, replies, and streams back a spoken response with a per-stage latency breakdown.

Client → Server
// binary WebSocket frames
// raw PCM16 mono, 16000 Hz, any chunk size
ws.send(int16Array.buffer)
Server → Client per turn
{
  "type": "turn",
  "transcript": "...",
  "reply_text": "...",
  "audio_b64": "...<mp3 reply>",
  "latency_ms": {
    "stt_ms": 405.1,
    "llm_ms": 574.1,
    "tts_first_byte_ms": 315.9,
    "tts_complete_ms": 173.0,
    "total_ms": 1461.3
  }
}
